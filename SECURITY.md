# Security Policy

## Reporting a Vulnerability

If you believe you have found a security vulnerability in this repository,
please report it through GitHub's [Private Vulnerability Reporting](https://github.com/amplitude/github-agent/security/advisories/new)
rather than opening a public issue.

You may also email `security@amplitude.com`.

We will acknowledge receipt within 3 business days and aim to provide an
initial assessment within 7 business days.

## Scope

This repository packages the Amplitude plugin for GitHub Agent HQ. Reports
about Amplitude's broader products and services should be sent to
`security@amplitude.com` directly.
